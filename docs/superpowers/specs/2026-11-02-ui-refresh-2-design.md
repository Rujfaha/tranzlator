# Tranzlator — UI Refresh 2 Spec

ต่อยอด `2026-11-01-ui-refresh-design.md` (token/motion/toast เดิมใช้ทั้งหมด) — 3 เรื่อง

## 1. Overlay suggestion แทนแถว KeySuggestion

ลบแถว `KeySuggestion` ที่ฝังในหน้า (ทั้งเว็บและมือถือ) → เปลี่ยนเป็น **bubble ลอย (coach mark)** ชี้ไปที่ไอคอนตั้งค่าใน header

```
                                   (⚙•)
                                     ▲
             ┌───────────────────────┴──┐
             │ [KeyRound] ใส่ API key ของคุณเพื่อเริ่มแปล   [X] │
             │ เลือกผู้ให้บริการและใส่ key ในการตั้งค่า          │
             │                       [ ไปที่ตั้งค่า ] │
             └──────────────────────────┘
```

- พื้น `graphite`, ตัวอักษร `paper`, radius `container`, `shadow-popover`, กว้างสุด 320 (มือถือ: เต็มกว้าง − 32), padding 16
- ลูกศรสามเหลี่ยม 12px ชี้ขึ้นตรงกลางไอคอนตั้งค่า (วัดตำแหน่งจริงด้วย `measureInWindow`/`onLayout`), bubble ชิดขวาตามไอคอน
- ปุ่ม "ไปที่ตั้งค่า" = pill `paper` ตัวอักษร `ink` → เปิดตั้งค่าและปิด bubble; `X` = ปิด
- **แสดงเมื่อ:** โหลดเสร็จและยังไม่มี key (หน่วง 400ms หลัง render แรก) และทุกครั้งที่กด "แปล"/Ctrl+Enter ตอนไม่มี key (แทน toast info เดิม)
- **ไม่แสดง:** มี key แล้ว; ผู้ใช้กด `X` แล้วใน session นี้ (จำใน state — reload แล้วแสดงใหม่)
- ไม่บังการพิมพ์: ไม่มี backdrop, แตะที่อื่นไม่ปิด (ปิดด้วย X หรือไปที่ตั้งค่าเท่านั้น)
- Motion: เข้า = opacity 0→1 + scale .96→1 + translateY −4→0, จุดหมุนที่ปลายลูกศร (`standard` 300ms); ออก 200ms; reduced motion = fade
- a11y: `accessibilityRole="alert"` ตอนปรากฏ, โฟกัสไม่ถูกขโมย
- ปุ่ม "แปล" ตอนไม่มี key: **ไม่ disabled** อีกต่อไป (ดูเหมือนกดได้) — กดแล้วแสดง bubble; ยัง disabled เมื่อข้อความว่าง/เกิน 2000/กำลังโหลด
- badge จุดบนไอคอนตั้งค่าคงไว้

## 2. มือถือ: กล่องแปลโค้งแบบแอป Google Translate (รูป 58471)

```
┌──────────────────────────────┐ ← พื้นหลังหน้า = shell
│┌────────────────────────────┐│
││ [mark] tranzlator     (⚙•) ││   แผ่นบน (paper)
││                            ││   header + ช่องพิมพ์ + ผลแปล อยู่บนแผ่นนี้
││ แปลข้อความ                  ││
││ ( วาง )                     ││
││ ...การ์ดผลแปล...             ││
││            ────            ││   handle 40×4 สี line
│╰────────────────────────────╯│   มุมล่างโค้ง 32 (โค้งเว้าเข้าหาแถบล่าง)
│  [ตรวจหาภาษา] → [อังกฤษ v]   │   แถบล่างบนพื้น shell
│  [           แปล          ]  │   pill บนพื้น shell = paper
└──────────────────────────────┘
```

- แผ่นบน: `paper`, มุมบนชิดจอ (0), **มุมล่าง radius 32** (`rounded-b-sheet` — เพิ่ม token `borderRadius.sheet: 32px`), เงา `card` ด้านล่าง, scroll ภายในแผ่น
- handle ตรงกลางขอบล่างของแผ่น (ตกแต่ง ไม่ลากได้)
- แถบล่าง: พื้น `shell` (ไม่มีเส้นขอบบนแล้ว), pill ภาษาพื้น `paper`, ปุ่มแปล `graphite`
- คีย์บอร์ดเปิด: แผ่นบนหดสูง แถบล่างอยู่เหนือคีย์บอร์ด (พฤติกรรมเดิม)
- ใช้เฉพาะ layout มือถือ (< 768) — จอกว้างไม่เปลี่ยน

## 3. หลายภาษาแบบ Google + ค้นหาภาษา

### ข้อมูลภาษา
- ไฟล์เดียวใช้ร่วม: `shared/languages.ts` → `export const LANGUAGES: readonly { code: string; th: string; en: string }[]` + `type Lang = string` + `isLang(code): boolean` + `langName(code): string` (ชื่อไทย, ไม่รู้จัก → คืน code)
- **รายการ code:** ตามหน้า Language support ของ Google Cloud Translation (ตรวจจากเอกสารจริงตอน implement) — คาดว่า 130+ ภาษา
- **ชื่อ:** สร้างครั้งเดียวด้วยสคริปต์ Node `scripts/gen-languages.mjs` ใช้ `Intl.DisplayNames(["th"], {type:"language"})` และ `["en"]` แล้ว commit ผลลัพธ์ (ไม่เรียก Intl ตอนรันบน Hermes); ชื่อที่ Node คืนเป็น code ดิบให้แก้มือในไฟล์ generate
- เรียงตามชื่อไทย (`localeCompare(..., "th")`)
- Worker: `validateTranslate` ใช้ `isLang` แทน LANGS 7 ตัว; prompt ใส่ทั้ง code และชื่ออังกฤษของภาษาปลายทาง (เช่น `Haitian Creole (ht)`) เพื่อให้ AI ไม่สับสน
- ภาษาที่ตรวจพบ (`sourceLang`) แสดงด้วย `langName`

### ค้นหาภาษา
- ฟังก์ชันกลาง `searchLanguages(q: string): Lang[]` — ไม่สนตัวพิมพ์/ช่องว่างหัวท้าย, จับคู่ **ขึ้นต้น** ชื่อไทย/อังกฤษ/code ก่อน แล้วค่อย **มีอยู่ใน** ชื่อ; q ว่าง → ทุกภาษา
- **เว็บ (popover จากปุ่ม `ChevronDown`):** ช่องค้นหาด้านบน (ไอคอน `Search`, placeholder "ค้นหาภาษา", autofocus), ใต้ลงมา grid 4 คอลัมน์ (≥1024) / 3 คอลัมน์, สูงสุด 420 แล้ว scroll; คีย์บอร์ด: ↑↓←→ เลื่อนตัวเลือก, Enter เลือก, Esc ปิด; ตัวที่เลือกอยู่มี `Check`
- **มือถือ (หน้าเลือกภาษาเต็มจอ, width < 768 ทั้งเว็บ responsive และ Android)** จัดแบบรูป 58476 (`inspirebygoogle/58476.jpg`) — ปุ่มย้อนกลับ ปุ่มค้นหา และหัวข้อเป็นองค์ประกอบแยกกัน:
  - **แถว 1 (app bar สูง 56):** ปุ่ม `ArrowLeft` ชิดซ้าย และปุ่ม `Search` ชิดขวา (ทั้งคู่ `PressableScale` 44×44) — ไม่มีอย่างอื่นในแถวนี้
  - **แถว 2 (แยกอยู่ด้านล่าง ชิดซ้าย padding 16):** หัวข้อ "แปลเป็นภาษา" `text-title` (28px) `font-sans-semibold`
  - จากนั้นหัวข้อย่อย "ภาษาที่ใช้ล่าสุด" / "ภาษาทั้งหมด" และ list (`FlatList`, ทุกภาษา)
  - **กด `Search`:** แถว 1 กลายเป็นช่องค้นหา — `ArrowLeft` อยู่ซ้ายเหมือนเดิมแต่ความหมายเปลี่ยนเป็น "ออกจากการค้นหา", ช่อง "ค้นหาภาษา" (autofocus) เต็มพื้นที่ที่เหลือ, มีปุ่ม `X` ล้างทางขวาเมื่อมีข้อความ; แถว 2 (หัวข้อ) หุบหายด้วย fade + ลดความสูง 200ms `standard` (reduced motion = fade อย่างเดียว); ซ่อนหัวข้อย่อย "ภาษาที่ใช้ล่าสุด" ระหว่างค้นหา
  - **ย้อนกลับ:** `ArrowLeft` ตอนค้นหา = ออกจากการค้นหา (ล้างคำค้น หัวข้อกลับมา); ตอนไม่ได้ค้นหา = ปิดหน้า; ปุ่ม back ของ Android ทำตามลำดับสองขั้นเดียวกัน
  - popover เว็บ (≥ 768) ไม่เปลี่ยน
- ไม่พบ: "ไม่พบภาษาที่ตรงกับ “{q}”" สี `muted`
- **จำค่า:** ภาษาปลายทาง + recents (3 ตัว) บันทึกด้วยกลไกเดียวกับ `settings.ts` (เว็บ localStorage / native SecureStore) คีย์แยก `tranzlator.langs`; เปิดใหม่ได้ค่าเดิม

| ไม่พบ | ไม่พบภาษาที่ตรงกับ “{q}” |
