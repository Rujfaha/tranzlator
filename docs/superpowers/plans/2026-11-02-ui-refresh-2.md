# UI Refresh 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** overlay suggestion ชี้ไอคอนตั้งค่า, กล่องแปลมือถือมุมล่างโค้งแบบแอป Google, รองรับภาษาแบบ Google (130+) พร้อมค้นหาภาษา

**Architecture:** รายการภาษาไฟล์เดียว `shared/languages.ts` ใช้ทั้ง worker และแอป; UI เปลี่ยนเฉพาะ component ที่ระบุ

**Tech Stack:** เดิม — ห้ามเพิ่ม dependency

**Spec:** `docs/superpowers/specs/2026-11-02-ui-refresh-2-design.md`

## Global Constraints

- Token/motion/copy เดิมทั้งหมดยังบังคับ (`docs/superpowers/specs/2026-11-01-*.md`); token ใหม่ได้เฉพาะ `borderRadius.sheet: 32px`
- ทุกปุ่มใช้ `PressableScale`; ทุก animation เคารพ reduced motion
- แก้ worker ได้เฉพาะ `worker/validate.ts` และ prompt ใน `worker/ai.ts` (ใช้ชื่ออังกฤษ+code); API shape และ D1 schema ห้ามเปลี่ยน
- tsconfig ทั้งสองชุดต้อง include `shared/`

## Review Focus

1. ค้นหา "จีน" ต้องได้ทั้งจีนตัวย่อ/ตัวเต็ม; ค้นหา "zh" และ "chinese" ได้ผลเดียวกัน (Task 1 test)
2. `sourceLang` จาก AI เป็น code ที่ไม่อยู่ในรายการ (เช่น "und") → แสดง code ดิบ ไม่ crash (Task 1 test)
3. ค่า `tranzlator.langs` ที่บันทึกไว้มี code ที่ไม่รู้จัก/JSON เสีย → ใช้ค่าเริ่มต้น (Task 3 test)
4. bubble ต้องไม่หลุดจอเมื่อจอแคบ 320 และหมุนจอ (Task 2 manual ที่ 320×640, 800×360)
5. เปิดตั้งค่าจาก bubble แล้วบันทึก key → bubble และ badge หายทันที (Task 2 manual)
